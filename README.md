# Image Screen Guard

แอป Android สำหรับสร้างภาพทับหน้าจอ (Screen Overlay Guard) เพื่อบังสายตา เพิ่มความเป็นส่วนตัว สามารถเลือูปภาพเองและปรับความโปร่งแสง (Opacity) ได้ตามต้องการ

## ฟีเจอร์หลัก
- เลือกรูปภาพจากคลังภาพในเครื่อง
- ปรับค่าความโปร่งแสง (Opacity) แบบ Real-time
- สัมผัสทะลุหน้าจอไปใช้แอปอื่นได้ปกติ (Touch-Through)
- ทำงานผ่าน Foreground Service
- Build APK อัตโนมัติด้วย GitHub Actions

## วิธีการใช้งาน
1. เปิดแอปและอนุญาตสิทธิ์ "Draw over other apps" (Display over other apps)
2. กดปุ่ม "เลือกรูปภาพบังสายตา"
3. ปรับแถบความโปร่งแสงตามต้องการ
4. กด "เปิดใช้งาน Screen Guard"
